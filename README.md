# CyberShield AI

AI Cyber Threat & Fraud Detection dashboard (React + TypeScript + Vite + Tailwind CSS).

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Notes

- Works offline using the built-in rule-based engine.
- Optionally add a Gemini API key from the in-app settings to enable LLM analysis (stored in your browser's localStorage).
